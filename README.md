# IWC website draft (Studio Jam)

Design draft of the new iwcwaste.com for Integrated Waste Consulting. Static HTML, CSS and JS with no build step.

Pages: `index.html` (Home), `ltl-waste-management.html`, `equipment.html`, `about.html`, `contact.html`.

- This is a draft. Every page has `noindex`, so search engines skip it.
- Dashed boxes mark photos and footage still coming from IWC.
- Add `?motion=off` to any URL to turn the animation off.
- Fonts: Strata and Beacon from fontzz, SIL Open Font License (`fonts/OFL.txt`).
